# Contributing to FirstIssue Radar

Thanks for your interest in contributing! This project helps newcomers find real, open GitHub issues matching their language and skill level.

## Getting started

1. Fork the repo and clone your fork.
2. Install dependencies: `npm install`
3. Copy env: `cp .env.example .env.local` (GITHUB_TOKEN optional but recommended).
4. Run dev server: `npm run dev`

## Before submitting a PR

- Run `npm run typecheck`, `npm run lint`, and `npm run build` — all must pass.
- Keep changes focused and well-described.
- Add tests or manual verification notes when behavior changes.
- Update docs/README if you change public behavior.

## Commit style

Use clear, imperative commit messages (e.g. `Add CONTRIBUTING guide`). Reference issues with `#123`.

## Reporting issues

Use the issue templates. Include steps to reproduce, expected vs actual behavior, and environment details.

## Code of Conduct

Be respectful and constructive. See CODE_OF_CONDUCT.md.
